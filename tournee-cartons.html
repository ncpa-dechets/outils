Contraintes du planning

Les jours fixes et le nombre de passages par semaine se règlent point par point dans l'onglet Paramètres (tableau « Fréquences et jours de passage »). Le planning reprend la clé openrouteservice, le départ, l'exutoire et le temps par arrêt de l'onglet Tournée.
Décoché : les groupes saisis dans Paramètres sont conservés.

Méthode

  1. Points à jours fixes : placés sur leurs jours, et sur les semaines prévues par leur fréquence.
  2. Points à jours libres : le planning leur choisit un jour (ou plusieurs, espacés de l'écart mini s'ils ont plusieurs passages par semaine) et, si la case est cochée, leur semaine dans le cycle de 2 ou 4 semaines.
  3. Chaque point va dans la tournée où il ajoute le moins de trajet, sans dépasser la durée maxi. On n'ouvre une nouvelle tournée que si aucune n'a la place, de préférence un jour peu chargé.
  4. Amélioration : chaque point est retiré puis replacé au meilleur endroit, et on essaie de supprimer la plus petite tournée de chaque jour en redistribuant ses points, tant que cela réduit le total.
  5. Chaque journée est enfin découpée en tournées avec le même calcul que l'onglet Tournée.
Ce que le calcul cherche à réduire, dans l'ordre : le nombre de tournées, le nombre de camions nécessaires le même jour, puis le temps total. Le « plancher théorique » est le nombre de tournées qu'il faudrait si elles étaient toutes remplies jusqu'à la durée maxi : on ne peut pas faire moins.

Résultat

Charger les points, placer le départ et l'exutoire (onglet Tournée), régler les jours dans Paramètres, puis lancer le calcul.

Plusieurs tournées

Répartit les points du jour entre plusieurs tournées (plusieurs camions, ou plusieurs passages dans la journée), toutes avec le même départ et le même exutoire.
Durée = conduite + arrêts. Les tournées sont équilibrées en durée.

Fréquences et jours de passage par point

Jours fixes : cliquer sur les jours où le point doit être collecté (ex. Lu + Je = 2 passages par semaine, toujours ces jours-là). Passages / sem. : pour un point sans jour fixe, nombre de passages par semaine. Le planning (onglet Planning semaine) lui choisit alors ses jours, affichés en vert. Un point sans jour fixe ni planifié est pris quel que soit le jour de la tournée.
